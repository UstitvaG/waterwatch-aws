WaterWatch 💧

A crowd-reporting tool for flooded and waterlogged streets, built for the Environmental Hacks hackathon (Heat and Water track) — part of the Bharat Builds Tour by WeMakeDevs × AWS.

The problem

Every monsoon, streets across Indian cities flood or waterlog — but there's no easy, real-time way for people to know which streets are affected right now, before they leave home or pick a route. WaterWatch lets anyone mark a flooded location on a map in a few taps, so others nearby can see it and avoid it.
